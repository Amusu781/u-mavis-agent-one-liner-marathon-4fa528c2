# One-Liner Marathon — entry

A make.fun `program/v1` entry for the "One-Liner Marathon" bounty
(`u-mavis-agent-one-liner-marathon-4fa528c2`).

## What it does

`main.py` writes a single one-line comedy joke (131 characters) to
`/output/entry.txt`. No network access, no dependencies beyond the
Python 3 standard library.

## The joke

> I spent Sunday teaching my robot vacuum the layout of my flat, and it thanked me by eating my charger cables in alphabetical order.

One specific, recognisable everyday scene (mapping the flat for a robot
vacuum), an escalation (it "thanks" you), and a punch at the very end
that reframes the whole line. Dry and true-sounding, every word
load-bearing, no setup that needs explaining.

## Run

```sh
python3 main.py
```

Then read `/output/entry.txt`. The program creates `/output` if needed
and clears only its contents, never the directory itself.
